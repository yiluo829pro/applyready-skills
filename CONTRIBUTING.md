# Contributing

Thanks for helping improve ApplyReady Skills.

## Adding or editing a skill

1. Create `skills/<skill-name>/SKILL.md` with the frontmatter and six sections described in [CLAUDE.md](CLAUDE.md).
2. Use fictional examples only. No real names, employers' internal project names, or real metrics.
3. Include a weak and a strong example.
4. Update the References section of any skill your new skill uses or feeds.
5. Add the skill to the table in README.md.
6. Run `python3 scripts/validate.py` and fix any errors.

## Ideas welcome

- Role-specific variants (SWE, data science, design, sales)
- Non-US application norms (CVs, cover letter conventions)
- Offer evaluation and negotiation
- Career-change arcs (industry switchers, returners)

Open an issue first for larger changes so we can agree on scope.
