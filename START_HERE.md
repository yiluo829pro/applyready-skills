# Start Here (60 seconds)

**Week 1, once (about 2 hours total):**

```
Use the story-bank skill. Interview me one era at a time.
Here's my resume: [paste]
```

Then:

```
Use the career-arc-builder skill with my story bank.
Target role types: [list]
```

Save both outputs. If you use Claude Projects, upload them as Project files.

**Every job description after that (30 to 45 minutes):**

```
Use the job-application-workflow skill.
JD: [paste]
Constraints: [location, comp floor, remote]
```

**When you get an interview loop:**

```
Use the interviewer-game-plan skill.
Company: [name]  Role: [title]
Schedule: [interviewer names and titles]
```

Then hand off to your interview-prep skills (for example, InterviewReady Skills) for practice and the day-of brief.
